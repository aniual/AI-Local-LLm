# AI 模型与开发技术研究

> 本目录用于长期沉淀 AI 模型原理、模型部署、推理引擎、Python / PyTorch / Transformers、AI Agent、多智能体系统及相关工程实践。

## 文档规范

- 正式技术方案统一放入 **docs/**。
- 使用中文撰写，保留必要的英文专业术语、API、代码标识。
- 每份方案包含：背景与目标、术语解释、架构图、技术选型、关键原理、实施路线、风险、验收标准和参考资料。
- 版本采用 V1.0、V1.1、V2.0；重大方案调整时新建版本或变更记录，不静默覆盖历史结论。
- 图示优先使用 Mermaid 和本地 SVG；不依赖不稳定的外部图片链接。
- 数学公式统一使用行内 `$...$`、行间 `$$...$$`，避免使用 `\\(...\\)` 与 `\\[...\\]` 作为 Markdown 定界符，以兼容 Obsidian 与 VS Code 内置预览。
- 颜色语义统一：
  - 🔵 蓝色：基础原理、架构、信息流。
  - 🟢 绿色：推荐方案、通过的验收项。
  - 🟠 橙色：注意事项、性能权衡、待验证项。
  - 🔴 红色：风险、错误配置、安全边界。
  - ⚪ 灰色：背景信息、可选能力。
- 文档中的“推荐”不等于“已经部署”或“已经验证”。每项能力必须标记为设计建议、待验证或实测通过。

## 研究范围

1. AI 模型基础：Transformer、Attention、MoE、MLA、GQA、量化与上下文机制。
2. 模型开发：Python、PyTorch、Transformers、Datasets、PEFT、LoRA / QLoRA。
3. 本地推理：Ollama、llama.cpp、vLLM、SGLang 及其他适用引擎。
4. AI 应用：Embedding、Reranker、RAG、工具调用、MCP、Agent 与多 Agent。
5. 工程化：GPU 资源管理、缓存、并发、服务治理、监控、评测和安全。
6. 模型服务：本地部署、云端 API、混合路由、成本和隐私控制。
