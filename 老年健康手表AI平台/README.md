# 老年健康手表 AI 平台

本目录用于建设基于第三方老年健康手表的健康监测、趋势分析、风险预警、AI 健康管理和家属协同平台。

## 当前资料

- 用户提供的《手表协议与算法调用链 V1》：设备双向协议、Protobuf 字段、下行指令、厂商算法调用链。
- 老年健康手表首页原型：产品功能与交互参考，不代表全部数据能力已验证。
- 《健康 AI 多智能体集群——各 Agent 完整实现路线详解》：儿童健康 AI 方案，作为架构参考，不直接照搬。
- 新增三份算法方案：用于研究参考，已进行独立的真实性、证据和老年场景适用性核验。

## 当前决策

- 先建立真实设备数据闭环和协议验证。
- 风险计算由可审计规则和经过验证的算法负责。
- LLM 负责解释、知识检索和健康管理辅助，不负责诊断和最终风险定级。
- V1 暂不训练大模型、不做 LoRA 微调、不建设 11 个独立 Agent。
- 本地模型通过现有本地 AI 推理平台统一 API 接入。
- PPG 心率、呼吸率、PRV 等必须先通过当前设备和老年人群验证。
- 不使用当前三份方案中的中医脏腑映射、消化趋势定级、代谢/血糖趋势定级和儿童哮喘 PPI 作为生产算法。
- 所有“推荐方案”均为设计建议，未通过真实设备和专业验证前不得标记为已上线能力。
