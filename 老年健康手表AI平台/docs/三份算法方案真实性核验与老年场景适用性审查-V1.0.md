## 0. 最终结论

### 0.1 总体判断

**三份文档中可复用的是部分信号处理、数据质量控制、个体基线和可审计工程思想；不能直接复用的是将 PPG/PRV/HRV 映射为脏腑、消化功能或代谢状态的判定逻辑。**

当前建议：

- 可以进入工程原型：原始信号归档、信号质量评估框架、心率提取、呼吸率研究性提取、PRV 计算、睡眠/活动上下文、个人趋势统计。
- 必须经过老年人群对照验证后才能进入产品：PPG 呼吸率、PRV/HRV 趋势、睡眠期指标、血氧、血压。
- 暂不允许进入正式健康风险判定：中医功能态、消化系统节律等级、代谢节律/血糖变化推断、儿童喘息 PPI 严重度规则。
- 不能用免责声明、词表过滤、LLM 固定枚举或“非医疗”命名替代算法有效性验证。

### 0.2 三份文档的审查结论

| 文档 | 工程架构价值 | 核心算法证据 | 老年人群可迁移性 | 当前决策 |
|---|---|---|---|---|
| PPG 中医手表方案 | 中高 | 部分信号处理有研究依据；中医功能态映射缺乏验证 | 需重新验证；大量内容为儿童场景 | 保留信号层，删除未经验证的状态映射 |
| 消化系统节律趋势 | 中 | HRV 与胃肠自主神经存在关联，但不能等同胃肠功能 | 缺少特异性和老年验证 | 不上线消化功能结论，只保留研究性数据分析 |
| 代谢节律趋势 | 中 | 个人基线方法可研究；不能由 HR/HRV/PPG 证明血糖趋势 | 无法直接迁移为代谢风险算法 | 不上线代谢/血糖趋势判定 |

### 0.3 证据等级

| 等级 | 含义 | 本项目处理 |
|---|---|---|
| A | 有较强、可重复的生理学/方法学证据，但仍需验证当前设备 | 可作为算法原型依据 |
| B | 有研究支持，但适用人群、设备、场景或指标有限 | 仅限研究性原型 |
| C | 生理关联存在，但不足以支持文档中的具体结论 | 不得形成用户健康结论 |
| D | 当前逻辑不成立、证据错配或存在明显方法学错误 | 从生产方案中删除 |
| U | 设备字段、单位、采样或来源未确认 | 不允许进入算法计算 |

## 1. 审查边界：什么叫“可以用于真实场景”

算法上线前必须分别通过六个门槛：

1. 生理机制成立：测量信号确实与目标生理量有关，而不是仅有表面相关性。
2. 测量方法成立：传感器、采样率、佩戴位置和信号处理可以稳定测到该量。
3. 目标人群成立：在老年人、心律失常、血管疾病、服药人群中仍有可接受表现。
4. 当前设备成立：采购手表真实提供所需原始数据、采样频率、时间戳和质量信息。
5. 算法性能成立：与合适参考设备同步比较，并在独立数据集上通过预设标准。
6. 产品用途成立：输出内容、预警用途和风险控制符合产品实际使用边界。

仅仅有论文证明“某种信号和某个生理状态相关”，不能证明该手表可以准确检测该状态。

## 2. 文档一：PPG 中医手表技术方案 V1.0

### 2.1 PPG 的物理测量边界

PPG 通过光学方式测量外周组织血容量随脉搏变化产生的光学信号。它可以支持心率、脉搏间期、部分呼吸调制和外周灌注相关特征提取。

它不能直接测量肝、心、脾、肺、肾等脏器的结构或功能，也不能仅凭腕部波形诊断脏器疾病。

**审查判断：PPG 的基本物理边界描述正确；将波形特征映射为五脏功能状态的做法没有因此获得科学依据。**

### 2.2 PPG 心率、呼吸率、PRV/HRV

| 算法能力 | 文档主张 | 核验结果 | 老年场景建议 |
|---|---|---|---|
| 心率 HR | PPG 可准确测量 | 原理成熟，但腕部运动、低灌注、接触压力、皮温和心律不齐会引入误差 | 可做，但需与 ECG 在静息、活动和不同灌注条件下验证 |
| 呼吸率 RR | 通过 RSA、幅度调制、基线调制提取 | 方法成立；可靠性依赖静息/睡眠、信号质量和算法实现 | 作为研究性功能优先验证，不能直接用儿童参数 |
| PRV | 可近似 ECG-HRV | 有条件近似，不是同一个生理量，也不能普遍互换 | 数据字段应命名为 PRV；与 ECG 同步验证后才允许做个人趋势 |
| SpO₂ | 双波长 PPG 可估计 | 原理成立，但腕部反射式 PPG 与指夹式医用血氧仪并不等价 | 当前设备单位、光源和测量验证未确认前不用于风险规则 |
| 外周灌注 | 可由波形间接反映 | 可以提取相关特征，但受温度、血管张力、佩戴松紧影响 | 作为信号质量/上下文特征，不解释成器官状态 |
| 脉搏波形态 | 可提取斜率、振幅等 | 可计算；但特征受硬件、佩戴、血管和滤波算法影响 | 先做设备内一致性和 ECG/参考信号验证 |

#### 2.2.1 PRV 不能直接称为 HRV

- ECG-HRV 通常由 ECG 的 R-R/NN 间期计算。
- PPG-PRV 由外周脉搏波到达时间间隔计算。
- 两者差异会受到脉搏传导时间、血管张力、外周循环、动脉僵硬、运动、接触状态和信号处理影响。
- 同一个人不同时间的外周血管状态改变，也可能造成 PRV 与 ECG-HRV 的偏差变化。

2026 年系统综述纳入 43 项研究，但只有 10 项研究进入定量合并，主要证据来自健康或表面健康人群的静息/受控条件。作者明确指出，不能将结果推广到睡眠、运动、压力或自由生活环境，也不能据此认为 PRV 与 ECG-HRV 可互换。

针对平均年龄约 70.6 岁的血管手术患者，腕部 PPG 研究显示部分 SDNN 等指标可能有监测价值，但 LF/HF 等指标需要谨慎解释。该研究仅 29 名患者，不能直接代表所有老年人。

**生产决策：**
- 保留 PRV_RMSSD、PRV_SDNN 等明确标记为 PPG 来源的指标。
- 不将其直接写成 ECG-HRV。
- 不用 PRV 单独判断交感神经增强、迷走神经不足或脏器功能。
- 出现房颤、频发早搏、明显不规则脉搏或低质量信号时，暂停常规 HRV/PRV 趋势解释，转入节律异常/数据不可用状态。

### 2.3 采样率 25 Hz 是否足够

文档把 PPG 25 Hz 作为最低要求，但这不能作为所有腕部设备和所有 HRV 指标的统一硬件准入线。

公开研究存在设备、算法和场景差异：

- 一项 2017 年受控实验的下采样研究认为，在其测试条件下，PPG 采样率不低于 25 Hz 时，部分时域和频域 PRV 参数与高采样参考接近。
- 另一项腕部光学传感器研究认为，64 Hz 对其研究的多项 HRV 指标更合适，RMSSD、pNN50 等指标对采样率要求更高。
- 2024 年的研究在特定传感器位置和直立体位下发现，约 100–200 Hz 才能使 PRV 偏差低于 2%；40–50 Hz 时偏差仍可能较大。
- 另有研究指出，信噪比和脉搏波形变化对逐搏间期误差的影响可能比单纯采样率更大。

这些研究说明采样率必须与传感器位置、峰值检测、亚采样插值、信噪比和目标指标一起验证。

尤其值得参考的是一项真正纳入老年患者的研究：29 名平均年龄 70.6 岁的血管手术/介入住院患者，使用 25 Hz 绿色腕部 PPG 与 1 kHz ECG 同步比较。研究使用专门的逐搏间期估计算法，并将 PPG 上采样到 200 Hz、采用 5 分钟分析窗；通过质量筛选后，整体有效覆盖率约为 30%。其中 SDNN 相对 MAE 约 9%，RMSSD 相对 MAE 约 17%，LF/HF 相对 MAE 约 36%，且研究者明确建议谨慎使用 LF/HF。研究还排除了起搏器患者，样本以白人患者为主。

这项研究说明：在特定设备、专门算法和严格质量门控下，25 Hz PPG 可能支持部分老年患者的特定 PRV/HRV 指标研究；但它绝不证明普通 25 Hz 手表可以全天稳定输出 HRV，更不证明所有指标都可用。约 30% 的有效覆盖率本身就是必须纳入产品设计的限制。

**本项目决策：25 Hz 只能作为待测参数，不可作为已证明的硬件准入标准。** 当前手表协议没有明确给出 PPG 原始数据的实际采样频率，必须向厂商确认并通过真实采样时间戳/波形回放核验。

### 2.4 呼吸频率提取是否可用于老年手表

PPG 呼吸率可通过多条调制通道估计：

- RSA：呼吸引起的心搏间期变化；
- AM：呼吸引起的脉搏波幅度变化；
- BM：呼吸引起的基线变化。

方法在研究中成立，但三路输出不是天然独立的“多数表决”。它们可能同时受到相同运动伪影、佩戴状态、呼吸深度和外周灌注变化影响。

公开睡眠研究中，腕部反射式 PPG 的呼吸活动代理信号在 389 份睡眠记录中，经质量和运动过滤后，估计误差约为 0.53±1.85 次/分；另一项 195 名睡眠中心受试者的智能手表验证研究也报告了较低的夜间呼吸率 RMSE。但这些结果属于具体设备、具体人群和具体睡眠场景，不代表当前采购设备达到相同性能。

**生产决策：**
- 先只在高质量静息/睡眠片段研究性输出呼吸率。
- 同时保存 RSA、AM、BM 各自的估计值、质量分数和可用状态。
- 不能把“多路一致”直接当作医学可信度。
- 必须与 RIP/胸腹呼吸带或 PSG 参考同步验证。
- 不能使用儿童文档的 0.15–0.80 Hz 呼吸频带和 32–60 秒窗口作为老年人的默认参数。

### 2.5 SQI 信号质量指数：方向正确，但文档没有真正定义算法

文档提出每分钟 SQI 0–1 或 0–100，并以低于阈值拒绝输出。这是正确的工程方向，但目前缺少：

- SQI 的明确数学定义；
- PPG 波形质量、峰值可辨性、灌注、运动能量、接触状态各自的权重；
- 不同设备/固件的归一化方法；
- SQI 与真实测量误差之间的校准曲线；
- 老年人低灌注、皮温低、血管病和心律不齐时的误拒/漏拒率。

不能先任意定义一个 SQI=0.7，再把它解释成“可信”。必须在配对参考数据中验证 SQI 与 HR、RR、PRV 误差的关系。

建议将 SQI 拆为多个可解释子分数，而不是首期只输出一个黑盒分数：

- ppg_morphology_quality
- perfusion_quality
- motion_quality
- contact_quality
- beat_detection_quality
- window_coverage

综合门控阈值由设备验证数据标定，并保留每项失败原因。

### 2.6 文档中的 D1–D8 中医功能态映射

文档第 16 页的 D1–D8 包含：
- 自主神经张力偏亢；
- 迷走张力不足；
- 昼夜节律偏移；
- 夜间恢复不充分；
- 应激后恢复迟缓；
- 气血运行偏滞；
- 昼夜波动过大；
- 整体平稳。

**这八个标签不能直接进入老年健康评估。**

主要问题：

1. D1 使用 LF/HF 代表交感/迷走平衡，当前 HRV 方法学不支持这种直接解释。
2. D2 把 RMSSD 下降直接解释为“迷走张力不足”，忽略年龄、药物、呼吸、心律、体位和信号来源。
3. D3 的夜间/日间 RMSSD 比值没有提供经老年人群验证的判定依据。
4. D4 把 SDNN、睡眠时长组合成“恢复不充分”，没有定义睡眠阶段、睡眠呼吸暂停、夜间觉醒和药物影响。
5. D5 “应激后恢复时间”没有定义应激事件起点、结束条件和恢复判据；单凭手表数据无法确认应激原因。
6. D6 的脉搏波振幅、上升支斜率会被佩戴压力、传感器增益、局部温度、灌注和血管僵硬影响。
7. D7 的日间心率极差受活动量和药物影响，不能直接解释成阴阳调节不稳。
8. D8 所有指标在 ±1σ 内不等于健康，也不排除稳定存在的慢性疾病。

2026 年 HRV 方法学指南再次强调，传统 LF 和 LF/HF 不适合用作心脏交感活动或交感-迷走平衡的特异指标；HRV 解释还应考虑呼吸、年龄、性别、测量部位和采集条件。

**生产决策：D1–D8 全部标记为 D 级，不进入风险引擎。** 若未来保留中医内容，只能作为独立的文化/知识解释模块，不允许由这些未经验证的映射生成个人脏腑状态。

### 2.7 子午流注与五运六气

- 十二时辰查表、干支推算属于确定性历法计算，适合用规则引擎实现。
- 文档中天干对应五运、地支对应司天的表格可作为规则实现的起点，但并不是完整的五运六气算法。
- 还需核验岁运、司天/在泉、主气/客气、六步时段、节气边界、岁首规则、时区和跨日处理。
- 这些时间标签是传统理论体系的文化信息，不是现代生理测量结果。

**生产决策：可以作为可选的传统文化时间展示，不得参与老年人心血管、呼吸、消化或代谢风险评分。**

### 2.8 儿童哮喘 PPI 算法不能迁移到老年人

该文档第 9–14 页的研究背景为 1–7 岁急性喘息儿童，P0 设计为 30 名儿童、每人 3 晚；P1 使用呼吸率、奇脉样波形 PPI、SpO₂ 等进行喘息严重度分级。

不能迁移的原因：

- 研究对象、呼吸生理、疾病机制和临床终点均为儿童急性喘息场景。
- PPI 的意义依赖特定的呼吸力学变化，不等于一般跌倒、心血管或老年呼吸风险指标。
- 文档中 ppi_flag and spo2_drop >= 3 的代码没有完整定义 PPI 算法、SpO₂ 基线、持续时间和测量质量。
- 研究中观察到的某一儿童队列特征，不足以支持老年人群的灵敏度、特异度或安全性。
- κ≥0.4、灵敏度 0.80、特异度 0.70 等阈值并不能自动成为老年预警的合格标准。

**生产决策：PPI 和儿童喘息严重度代码从老年平台生产算法候选中剔除。**

## 3. 文档二：消化系统节律趋势管理

### 3.1 HRV 与胃肠功能的关系

脑肠轴、自主神经和胃肠活动之间存在生理联系，这一基础方向成立。

但文档最重要的误区是把“心脏迷走神经活动的变化”推断为“腹部/胃肠迷走神经活动变化”。

文档引用的 Chang 等研究实际纳入 22 名健康志愿者，使用 ECG、餐后连续记录 HRV，并测量胰多肽、瘦素和胃饥饿素。研究发现餐后 HR、HF、LF 等变化，但结论明确指出：HRV 反映心脏活动，并不等价于腹部迷走活动；将 HRV 作为胃肠功能问题的腹部迷走测量需要谨慎，建议结合其他指标。

这篇研究不能支持“腕部 PPG-PRV 能测消化运化功能”。

### 3.2 餐后 HRV 响应逻辑存在问题

文档把“餐后 HRV 回升幅度”作为核心特征，但引用的 22 人研究中，餐后 HR 上升，HF 功率在餐后 40–120 分钟下降，LF/HF 比值上升。

因此：
- 餐后 HRV 的变化方向不是简单的“应该回升”。
- 不同 HRV 指标的餐后变化并不相同。
- 不能把一个指标的变化直接解释为胃肠动力增强或减弱。
- 需要区分食物组成、能量、进食速度、体位、活动、药物、血糖变化和胃肠疾病。

**生产决策：删除“餐后 HRV 回升=消化响应良好/不足”的直接判定。**

### 3.3 三套分时基线

文档定义：
- 辰巳脾胃基线：07:00–11:00；
- 餐后响应基线：餐后 0–120 分钟；
- 夜间胃肠修复基线：23:00–03:00。

问题：

1. 07:00–11:00 是中医时辰分区，不是已验证的现代胃肠功能检测窗口。
2. 23:00–03:00 不能直接代表胃肠修复；实际睡眠时间、进餐时间、夜班、睡眠障碍会改变上下文。
3. 餐后 0–120 分钟必须先有准确的进餐事件时间；当前手表协议没有餐食事件、餐量、营养构成和进食时间字段。
4. 固定时钟窗口会把作息差异和真实生理差异混在一起。

**生产决策：可将其保留为研究分组或用户日志分析窗口，不得命名为脾胃/胃肠功能基线。**

### 3.4 数据清洗规则

文档采用：
- 运动状态数据全部丢弃；
- PPG 低信噪比数据丢弃；
- IQR 剔除极值；
- 静息样本用于基线；
- 短时缺失小于 5 分钟线性插值。

审核结果：

- 运动数据应作为质量门控和上下文特征，不应一律从系统中永久丢弃。
- IQR 只能作为一种候选异常值方法，不能直接认定极端值就是噪声；真实的生理异常也可能是极端值。
- 线性插值不能用于补造 ECG/PPG 逐搏间期、SpO₂ 下降片段或呼吸波形。插值会制造并不存在的生理变化，尤其会扭曲 RMSSD 等相邻间期指标。
- 缺失数据应保留为缺失并标记原因；仅可在展示层对趋势线做视觉连接，不能把插值值输入风险计算。

### 3.5 15%、5 天、7 天阈值

这些值在文档中已注明为工程参数，没有可直接适用于所有人的医学阈值证据。

即使使用个人基线，也不能推导出：
- HRV 偏移 15% 就是消化节律异常；
- 连续 5 天就代表胃肠功能失调；
- 连续 7 天就代表夜间胃肠修复下降。

多日持续过滤可以降低部分短期噪声，但也可能延迟发现真实问题。急性事件不能被“至少持续 5–7 天”规则屏蔽。

**生产决策：阈值仅可用于离线实验，不能用于用户健康风险提示。**

### 3.6 GLM4 定级与中医模型融合

文档把 GLM4 作为唯一趋势等级来源，杏核模型负责中医解释。

问题：
- LLM 输出固定枚举并不等于模型具备可靠的生理分类能力。
- GLM4 的训练数据、标签定义、外部验证和错误率均未给出。
- 中医时间标签不是独立的生理测量证据。
- 个人基线 M3 与 M1 仍使用相同的 HR/HRV 数据，并不构成独立证据。
- “三路投票”容易重复计算同一信号，造成虚假的置信度。

**生产决策：健康风险等级由经过验证的确定性规则或经验证的专用模型输出；LLM 只解释已确定的事实，不负责定级。**

### 3.7 文档性能指标的证据错配

文档中的：
- 瞬时误报率小于 5%；
- 趋势判断准确率 ≥82%；
- 用户体感匹配率 ≥80%。

均不能直接视为消化系统算法的合理目标。

尤其是：
- 心律失常筛查设备的特异度不能移植为消化趋势的误报率。
- 抑郁筛查或心血管数字生物标志物的准确率/AUC，不能移植为胃肠功能趋势的准确率。
- “体感匹配率”必须先定义标准化问卷、时间窗、独立评估者和统计方法。

**生产决策：删除“量产精准”“误报率小于 5%”“准确率 82%”等未经本项目数据验证的表述。**

## 4. 文档三：代谢节律趋势健康管理

### 4.1 最关键的证据误读：Phillips & Naef 2023

文档把论文中的“加入活动、HR、HRV 后，模型最多额外解释 15% 的葡萄糖变异”解释为无创条件下生理信号对血糖变异的解释力上限。

这不是论文原意。

论文实际设计：
- 25 名健康参与者；
- 连续观察 14 天；
- 同时采集饮食/饮水事件、连续葡萄糖、活动、HR、HRV；
- 使用 Abbott FreeStyle Libre Pro CGM 作为连续葡萄糖测量来源；
- 用手机 App 记录食物和饮料摄入；
- 在已有葡萄糖时间序列作为建模目标的前提下，加入活动、HR 和 HRV 特征，最多额外解释 15% 的葡萄糖变异。

这意味着：
1. 论文不是用腕部 PPG 单独测量血糖。
2. 论文没有证明手表可以在没有 CGM 的情况下推断血糖。
3. “额外解释 15% 的葡萄糖变异”不是“无创血糖测量精度上限”。
4. 研究对象是 25 名健康人，不是老年慢病人群。
5. 该研究使用了进餐事件和 CGM 标签，而当前采购手表并不具备相同数据条件。

**这是文档中必须纠正的关键引用错误。**

### 4.2 不测血糖数值，不代表可以测血糖趋势

当前文档把输出改名为“代谢节律趋势”，但其内部规则仍然使用：
- 清晨空腹偏移；
- 餐后代谢回落；
- 夜间基础代谢；
- 代谢节律异常。

这些变量如果没有 CGM/血糖参考、进餐事件、运动和药物上下文，无法证明它们对应血糖或代谢变化。

“只输出趋势、不输出数值”只改变输出形式，不会让输入信号突然获得新的测量能力。

FDA 已明确提醒，不应使用没有相应授权的智能手表/戒指自行测量或估计血糖值。对本项目而言，即使不输出浓度，也不能宣称已有血糖趋势监测能力。

**生产决策：不得以当前手表 HR/HRV/PPG 数据输出血糖趋势、糖代谢异常、黎明现象或糖尿病风险结论。**

### 4.3 采集数据不满足文档模型前提

文档要求：
- PPG 原始波形 ≥25 Hz，建议 50 Hz；
- 三轴加速度 ≥25 Hz；
- HR 每分钟连续一次；
- HRV 的静息 RR 间期；
- 皮温每分钟一次；
- SpO₂ 每 5 分钟一次；
- 佩戴状态实时；
- 每日有效数据组数 ≥1500。

当前手表协议并没有给出这些条件全部满足的证据：
- PPG 有原始数据载荷，但没有在协议字段中明确实际采样频率。
- 加速度有三轴字段，但没有明确采样频率；陀螺仪类型存在但当前协议接入状态未完成。
- 手表上报间隔不等于传感器采样率。
- 协议中有分钟级 HR/HRV 字段，但不能由此证明原始逐搏间期在全天连续可用。
- 皮温来源、血氧单位和测量质量仍需厂商确认。
- 7×24 小时连续高质量佩戴不能由协议字段直接保证。

### 4.4 28 天基线与 7 天滚动更新

个人基线是合理的统计思想，但不是临床验证的替代品。

问题：
- 28 天并非所有指标、所有人群的固定最优基线长度。
- 7 天滚动更新可能过快地把持续恶化吸收进“新正常”。
- 若 L4 规则本身错误，基线冻结机制也会被错误触发。
- 老年人的用药调整、急性感染、住院、脱水、睡眠变化和心律改变会显著改变 HR/HRV。
- 不应在没有上下文标签的情况下将所有数据放入同一个基线。

建议：
- 使用设备/用户/测量条件分层的基线。
- 保留基线版本和更新历史。
- 采用稳健统计方法，并对疑似异常时段做隔离。
- 将“基线未建立”与“没有异常”区分。
- 个人基线仅作为变化参照，不用于替代血糖、血压或临床检查。

### 4.5 三重模型交叉验证并不成立

文档中的 M1、M2、M3：
- M1：GLM4 代谢模型；
- M2：中医节律模型；
- M3：个人基线模型。

这三路不是独立的三种证据：

- M1 不是已经定义并验证的代谢预测模型。
- M2 是根据时间标签和中医理论生成解释，不是对葡萄糖或胃肠生理的独立测量。
- M3 是同一批 HR/HRV 数据计算的个人参照，不能被当成第三个独立模型。
- 三路投票会造成同源数据重复计权，不能据此宣称置信度提高。

**生产决策：删除三路投票机制。改为“数据质量门控 + 特征计算 + 规则判定 + 独立验证 + AI 解释”。**

### 4.6 15% 偏移、5/7 天和 75–85% 目标

这些是文档自定义的工程参数，不是医学标准。

- 15% 偏移没有给出目标变量、单位、窗口、方差和重复测量误差。
- 连续 5/7 天只描述持续时间，不能证明目标是代谢。
- 75–85% 趋势方向目标没有定义金标准。
- 小于 8% 的误报目标没有定义统计单位、观察时间和分母。
- 不能把其他疾病/其他设备的模型准确率作为本算法目标的外部依据。

**生产决策：这些数值只能留在实验配置，不得用于产品宣传或上线验收。**

### 5.3 必须向厂商补齐的采集参数

1. PPG 原始波形真实采样率（Hz），是否动态调整。
2. PPG 每个数据点的单位、ADC 范围、增益、波长、LED 工作模式。
3. PPG 每包样本数、包起始时间、样本间隔、丢包标记和补传规则。
4. 加速度 x/y/z 的采样率、单位、量程、坐标系和时间戳。
5. RRI 数值单位、生成方式、异常间期标记、是否已经过滤早搏。
6. ECG 采样率、导联、量程、基线滤波、工频滤波和校准方式。
7. HRV 汇总值由 ECG 还是 PPG 计算，具体窗口长度和算法版本。
8. SpO₂ 字段单位、有效范围、接触/灌注质量标记和设备验证报告。
9. 血压测量物理原理、校准流程、验证报告和适用人群。
10. 血糖/血钾/尿酸字段究竟来自手表本体还是第三方终端，测量单位、原理和验证资料。
11. 每种原始序列的上报周期、存储缓存长度、断网补传完整性和最大连续采集时长。
12. 固件升级是否改变采样率、算法版本、字段含义或数据编码。

## 7. 面向老年健康手表的正确算法架构

建议后续统一使用以下流水线：

~~~mermaid
flowchart TD
    A[手表原始数据] --> B[协议解码与原始归档]
    B --> C[字段/单位/时间/版本校验]
    C --> D[信号质量与佩戴状态门控]
    D --> E{心律/信号是否适合该指标}
    E -- 否 --> F[数据不可用/需要复测]
    E -- 是 --> G[指标专用算法]
    G --> H[HR / RR / PRV / SpO2 / Sleep]
    H --> I[个体基线与上下文]
    I --> J[已验证的确定性规则]
    J --> K[风险事件状态机]
    K --> L[老人/家属通知]
    K --> M[AI解释已确认事实]
    N[审核知识库 RAG] --> M
    M --> O[健康简报/问答/计划草稿]
~~~

### 7.1 必须增加心律有效性门控

老年人群中心房颤、早搏、起搏器、传导异常和其他心律问题的比例更高。

常规 HRV 算法依赖可解释的正常窦性 NN 间期。出现房颤、频发早搏或明显不规则节律时：
- 不得继续把所有脉搏间期直接输入正常 HRV 公式。
- 不得把心律不齐误认为 HRV 增高/降低。
- PPG 可用于提示脉搏不规则，但不能据此确诊房颤。
- 对疑似房颤的结论，应提示通过 ECG/专业医疗评估确认。

2023 ACC/AHA/ACCP/HRS 房颤指南明确指出，基于 PPG 的智能手表不规则心率算法不足以确立房颤诊断。

### 7.2 急性事件与长期趋势必须分开

长期趋势算法可以要求连续多日有效数据，但 SOS、设备跌倒事件、严重单次异常或用户主动报告的急性症状不能被“至少持续 5–7 天”规则屏蔽。

必须分别实现：
- 设备原生 SOS/跌倒等快速事件；
- 经验证的即时测量异常提示；
- 多日个人趋势变化；
- 数据质量和设备异常提醒。

“没有触发趋势规则”不能被展示成“健康正常”。

### 7.3 个人基线的正确使用

建议：
- 按指标、时间窗、姿势/活动状态和设备版本分层建立基线。
- 使用中位数、MAD、分位数等稳健统计量作为候选方法。
- 保存基线建立时间、有效样本数、数据覆盖率和版本。
- 对急性感染、住院、药物调整、明显心律变化等时期进行事件标记。
- 允许基线暂停更新、重新建立和人工审查。
- 基线只回答“与本人近期常态相比有何变化”，不能回答“是否患病”。

## 8. 严格验证计划

### Phase A：硬件和数据能力确认

必须交付：
- PPG、ECG、RRI、ACC 的原始样本和采样率证明；
- 数据包时间戳、样本间隔、丢包、补传测试；
- 不同佩戴松紧、低灌注、运动和温度条件下的数据；
- 固件版本和算法版本对照表；
- SpO₂、血压、体温等指标的测量原理和验证资料。

Gate A：没有真实采样率和单位说明，不进入 PRV/RR/SpO₂ 算法精度开发。

### Phase B：基础信号精度验证

建议同步参考：
- HR/PRV：ECG Holter 或高质量 ECG 贴片；
- 呼吸率：RIP/胸腹呼吸带或 PSG；
- SpO₂：合适的医用脉搏血氧参考设备；
- BP：经过验证的上臂袖带血压计；若厂商方案属于无袖带估算，应先核实校准和独立验证；2025 AHA/ACC 高血压指南不建议将无袖带设备用于成人高血压诊断或管理。
- 睡眠阶段：多导睡眠监测 PSG。

报告指标：
- 可用数据覆盖率；
- 有效片段比例；
- MAE、RMSE；
- Bland–Altman 偏差和一致性界限；
- ICC/重复性；
- 按年龄、心律、血管状态、活动、佩戴质量分层。

### Phase C：老年人群前瞻性验证

不能只按“30 人 × 3 晚”作为生产验证规模。该规模最多用于流程可行性和初步参数估计，不能证明产品在不同老年人群中的准确性。

样本量应依据目标指标、预期误差、置信区间宽度、目标事件发生率和亚组分析需求进行统计设计。

至少应考虑：
- 60–69、70–79、80 岁以上；
- 有无房颤/早搏；
- 有无外周血管疾病；
- 糖尿病、慢性肾病等常见共病；
- 降压药、β 受体阻滞剂等常见药物；
- 不同皮肤/外周灌注条件；
- 白天活动、静息和夜间睡眠。

训练、阈值调优和测试必须按受试者分组，不能把同一人的不同夜晚随机分到训练集和测试集，否则会产生数据泄漏。

### Phase D：风险规则验证

每条规则必须预先定义：
- 目标事件和参考标准；
- 纳入/排除条件；
- 输入数据质量门槛；
- 判定窗口、持续时间和阈值；
- 灵敏度、特异度、PPV、NPV；
- 每人每天误报次数；
- 漏报和延迟发现的后果；
- 置信区间和失败处置。

不得只报告 Accuracy。老年人群事件发生率不同，单一准确率可能掩盖漏报。

### Phase E：上线后的安全监测

- 持续统计数据覆盖率和无效数据比例；
- 按设备固件、传感器批次和算法版本监测偏差；
- 记录用户/家属确认的误报和漏报；
- 新阈值必须经过离线回放、影子模式和灰度验证；
- 保留旧版本回滚能力；
- 不允许大模型自行更新风险阈值。

## 9. 文档中必须修正的关键错误/过度表述

| 原文观点 | 审查意见 | 修改方向 |
|---|---|---|
| PPG 心率变异性“很准” | 忽略 PRV 与 ECG-HRV 差异 | 改为“在指定设备、信号质量和静息条件下研究性估计 PRV” |
| 25 Hz 是最低准入线 | 研究结果依设备和指标而异；当前手表采样率未确认 | 改为“需按目标指标验证采样率与 SQI” |
| LF/HF 代表交感/迷走平衡 | 现代 HRV 方法学不支持这种直接解释 | 从核心状态算法中删除 |
| HRV 映射八种中医功能态 | 无老年人群效度研究 | 不进入生产判定 |
| 餐后 HRV 回升反映消化响应 | 引用研究的 HF 餐后变化方向并非简单回升，且心脏迷走不等于腹部迷走 | 改为探索性自主神经研究指标 |
| 辰巳时段异常等于脾胃异常 | 时间分区不能证明脏器功能 | 只保留文化性时间标签 |
| 15% 偏移 + 5/7 天即可判异常 | 无目标疾病/生理终点验证 | 只保留实验参数 |
| GLM4 固定枚举即可“无幻觉” | 格式约束不等于模型正确 | 由确定性规则定级，LLM 解释 |
| 三路模型投票可降低误报 | 三路输入并不独立，存在重复计权 | 删除投票，保留证据来源和规则 |
| HR/HRV 等可推导血糖趋势 | 论文实际使用 CGM 和进餐日志作为关键输入 | 不作为血糖/代谢监测功能 |
| 非医疗免责声明即可合规 | 产品预期用途、处理对象和核心功能才是重要判断因素 | 上线前单独开展法规分类评估 |

## 10. 监管与产品边界提示

本报告不对产品最终医疗器械分类作法律结论。

中国国家药监局《人工智能医用软件产品分类界定指导原则》强调，应结合预期用途、处理对象和核心功能综合判断；对医疗器械数据进行处理、测量、模型计算或分析，并用于医疗用途的软件，可能属于医疗器械管理。

《医疗器械软件注册审查指导原则（2022 年修订版）》也要求根据预期用途、使用场景、核心功能和风险程度开展软件验证与确认。

因此：
- “健康管理”“趋势参考”“非医疗”文字不能单独决定监管属性。
- 如果产品实际向老人/家属提供疾病筛查、病情恶化预警、诊断辅助或治疗建议，必须重新评估监管边界。
- 不应通过屏蔽“血糖”“诊断”等词语来规避实际功能和预期用途判断。
- 正式发布前需要针对目标销售地区完成产品分类、宣传用语和数据处理合规审查。

## 12. 最终工程决策表

| 算法/能力 | 当前决定 | 下一步 |
|---|---|---|
| PPG 原始波形解析 | 保留 | 确认采样率、时间戳、单位和分片 |
| PPG 心率 | 进入工程验证 | 同步 ECG 对照 |
| PPG 呼吸率 | 研究性验证 | RIP/PSG 对照，先限静息/睡眠 |
| PRV | 研究性验证 | 与 ECG-HRV 明确区分，按心律质量门控 |
| LF/HF | 不用于风险判定 | 不再解释为交感/迷走平衡 |
| 睡眠趋势 | 保留基础能力 | 验证睡眠阶段和夜间指标 |
| SpO₂ | 暂缓风险应用 | 厂商确认单位、质量和对照结果 |
| 血压 | 暂缓风险应用 | 核实测量原理并用合格袖带设备验证 |
| 中医 D1–D8 | 删除生产判定 | 如保留，仅作文化解释研究 |
| 子午流注/五运六气 | 可选展示 | 独立规则计算，不参与健康风险 |
| 消化节律趋势 | 不上线 | 需要独立胃肠参考终点和研究设计 |
| 代谢/血糖趋势 | 不上线 | 不以当前手表 HR/HRV 推断血糖 |
| 儿童哮喘 PPI | 不迁移 | 与老年项目无关 |
| 三重模型投票 | 删除 | 规则负责定级，AI 只解释 |
| RAG/LLM | 可建设 | 只提供可信知识和结构化解释 |

**最终原则：保留能被传感器真实测量、能被参考设备验证的指标；删除从相关性跳到器官/疾病结论的推断。任何算法在真实老年人群验证之前，都只能标记为研究功能，不得标记为已具备预警能力。**
