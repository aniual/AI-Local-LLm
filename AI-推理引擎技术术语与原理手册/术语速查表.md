## 七、最容易混淆的十组概念

| 概念 A | 概念 B | 核心区别 |
|---|---|---|
| 模型 | 推理引擎 | 被运行的参数/结构 vs 负责运行的软件 |
| GGUF | llama.cpp | 模型文件格式 vs 推理项目 |
| Ollama | vLLM | 易用模型管理/运行服务 vs 高吞吐推理引擎 |
| Prefill | Decode | 批量处理输入上下文 vs 自回归生成输出 |
| Weights | KV Cache | 模型参数 vs 请求运行时状态 |
| GQA | PagedAttention | 模型注意力结构 vs 缓存管理方式 |
| FlashAttention | PagedAttention | Attention 计算优化 vs KV Cache 分配/组织 |
| LiteLLM | FastAPI | 模型代理网关 vs 通用 Python API 框架 |
| Prometheus | Grafana | 指标采集/查询/存储 vs 可视化 |
| Concurrency | Throughput | 同时处理的任务数 vs 单位时间完成的工作量 |

## 八、使用建议

当开发过程中看到一个不理解的术语：

1. 先在本表查中文解释。
2. 点击对应专题文档，理解原理和上下游关系。
3. 回到原架构方案，确认它在哪个模块使用。
4. 开发时查对应组件当前版本的官方文档。
5. 用实际运行指标验证，不把理论能力当作实测结果。
